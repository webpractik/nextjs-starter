# Документация

Здесь описано, как устроен проект и как выполнять повседневные задачи. Выберите короткий маршрут
для знакомства с репозиторием или сразу перейдите к нужной задаче.

## Если вы здесь впервые

1. Запустите проект по [быстрому старту](../README.md#быстрый-старт).
2. Разберитесь с обязательными значениями в [переменных окружения](environment.md).
3. Перед первым изменением прочитайте [про слои и границы](architecture.md).
4. Перед отправкой изменений выберите проверки в [руководстве по тестированию](testing-guidelines.md).

## Что считать источником истины

Документы объясняют текущее поведение, но исполняемый код и конфигурация имеют приоритет. Правила
работы с репозиторием находятся в [`AGENTS.md`](../AGENTS.md). OpenSpec proposals описывают
планируемые изменения и не заменяют документацию текущего состояния.
