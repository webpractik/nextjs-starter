<a id="числовые-gates"></a>

## Числовые ограничения

- До 200 строк включительно обязателен только разбор ответственности.
- Для 201–800 строк обязателен документированный разбор декомпозиции.
- Рабочий файл компонента больше 800 строк не проходит проверку.

Считайте все физические строки: импорты, типы, функции, JSX, комментарии и пустые
строки. Исключайте тесты, Stories, фикстуры и сгенерированный код. Не уплотняйте
код и не объединяйте строки ради порога.

Для каждого файла длиннее 200 строк укажите причины его изменения, владельцев
ответственности, границы интерфейсов и точки замены, возможные выделения кода
без изменения поведения.

<a id="один-component-на-файл"></a>

## Один компонент на файл

В рабочем файле объявлен ровно один React-компонент; memo и forwardRef считаются
его обёртками. Вложенные компоненты запрещены, части составного компонента
занимают отдельные файлы. Точка входа может реэкспортировать компонент, но не
объявлять его. Тесты, Stories, фикстуры и сгенерированный код исключены.

Локальные типы, константы и вспомогательные функции допустимы, пока не создают
второй ответственности или компонента.

<a id="карта-extraction"></a>

## Карта выделения кода

| Ответственность | Куда выделять |
| --- | --- |
| Самостоятельная визуальная область | Компонент |
| Чистый инвариант или бизнес-правило | domain |
| Координация сценария | application |
| HTTP, хранилище, браузерный ввод-вывод | Адаптер infrastructure |
| Преобразование DTO и ошибок | Адаптер на границе |
| Подготовка данных для показа | Презентер или преобразователь модели представления |
| Внешняя подписка | Адаптер хранилища и хук useSyncExternalStore |

Не создавайте передающие вызов обёртки и однострочные абстракции ради размера.
Повторное использование необязательно: отдельная причина изменения уже
оправдывает выделение.

## Классификация Atomic Design

- Атом — неделимый примитив без доменной специфики.
- Молекула — небольшая композиция с одной задачей UI.
- Организм — самостоятельный раздел функционального модуля.
- Шаблон — структура страницы и слоты без конкретных данных.
- Страница — сборка на уровне маршрута с реальными данными и состоянием.

Stories создаются только для атомов и молекул. Организмы проверяйте компонентными
и интеграционными тестами, шаблоны — тестами структуры и раскладки, страницы —
интеграционными и E2E-тестами. Для этих трёх уровней Stories запрещены.

## Команды проверки

Получите средствами проекта список изменённых файлов или файлов в границах
задачи. Классифицируйте их вручную или инструментом с разбором AST: не каждый
`.tsx` содержит компонент. Первой проверке передайте только подтверждённые
рабочие файлы компонентов, второй — только относящиеся к задаче Stories.
Все подтверждённые файлы репозитория передавайте лишь при согласованном обзоре
всего проекта.

```bash
check_component_sizes() {
  local too_large=0 file lines
  for file in "$@"; do
    lines=$(awk 'END { print NR }' "$file")
    if [ "$lines" -gt 200 ]; then
      printf '%s %s\n' "$lines" "$file"
    fi
    if [ "$lines" -gt 800 ]; then
      too_large=1
    fi
  done
  return "$too_large"
}

check_story_levels() {
  local file invalid=0
  for file in "$@"; do
    if printf '%s\n' "$file" \
      | rg -q '(^|/)(organisms|templates|pages)/.*\.stories\.[jt]sx?$'; then
      printf 'forbidden Story level: %s\n' "$file"
      invalid=1
    fi
  done
  return "$invalid"
}
```

Передайте `check_component_sizes` выбранные рабочие файлы компонентов,
`check_story_levels` — файлы Stories. Первая проверка показывает кандидатов
по размеру и возвращает ненулевой код при превышении 800 строк; вторая
запрещает Stories верхних уровней Atomic Design. Количество компонентов
подтверждайте анализом AST и вручную. Регулярное выражение лишь находит
кандидатов. Если правила для AST нет, предложите минимальное и согласуйте новую
зависимость до изменения манифеста.

## Тревожные признаки

- Бизнес-решения принимаются в JSX или хуке-контроллере.
- Рабочий файл объявляет несколько компонентов.
- Вложенный компонент теряет состояние при рендере родителя.
- Код выделен только ради числа строк.
- Организм с логикой функционального модуля перенесён в shared.
- Story создана для организма, шаблона или страницы.
