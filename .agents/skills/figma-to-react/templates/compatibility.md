# Совместимость

- Задача: `<taskId>`
- Проект: `<точное название и стек проекта>`
- URL Figma: `<figmaUrl>`
- Источник: `<fileKey>`, версия `<fileVersion>`, узел `<nodeId>`
- Адрес проекта: `<origin>`
- Маршрут и целевой модуль: `<route>`, `<featureModule>`
- Разрешённые корни реализации: `<точный однострочный JSON allowedImplementationRoots>`
- Команда снимка: `<visualCaptureCommand>`
- Команда сравнения: `<visualCompareCommand>`
- Права: чтение Figma и запись только в разрешённые корни реализации, файл данных и согласованные файлы зависимости
